# Upstream

This directory contains the editable source of [`agegr/pi-web`](https://github.com/agegr/pi-web) `v0.8.6`, commit `dfab5853b8d2f717df259e7ebc94f49a3c2e43e7` (MIT).

Copied source excludes upstream Git metadata, release CLI files, upstream README/docs/screenshots/translations, build output, caches, and dependencies. MedPi science capabilities live outside this directory so upstream updates remain reviewable.

MedPi upgrades the four direct `@earendil-works/pi-*` runtime dependencies from the pi-web source baseline's `0.83.0` to `0.84.1` for upstream security fixes. Compatibility adaptations and verification are recorded in [`../../docs/science-platform-migration.md`](../../docs/science-platform-migration.md).
